# Suite-v2 Public-Seed Prefix

This is an exploratory two-seed prefix, not the 100-seed public baseline. It
accounts for six trials and passes the listed hard safety checks, but both
development embodiments completed 0/4 expected-success pushes. It confirms the
registered grasp fixture can succeed; it does not establish push availability
or cross-embodiment generality.

Use it only as diagnostic evidence. The full public baseline remains unrun, the
holdout was not touched, and the results are `SIMULATION_ONLY`.
